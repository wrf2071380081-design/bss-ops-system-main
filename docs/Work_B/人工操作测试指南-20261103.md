## 2. 建议的点击顺序（约 30 分钟）

### 流程 D · 客户开通全链（**本轮重点，10 分钟**）
1. 「客户管理」→ 右上「**新建客户**」
2. Step1 填：客户名称写个新的（如 `人工测试-<时间>`）、销售归属选自己、国内、CNY、税率 `0.06` → 「创建并继续」

3. Step2：「是否首单」保持开启 → 合同与授信办理人、资源配置办理人选自己 → 「查询来源」→ 在候选里「加入」一个 → 「发起开通」

4. 关掉弹窗 → 进该客户详情 →「**档案与办理**」Tab
   - ✅ 预期：「开通流程」卡片有两个节点：**合同与授信（办理中）**、**资源配置（等待前序）**

## 3. 已知边界：看到这些**不是 bug**

| 现象 | 原因 |
|---|---|
| 客户列表「服务中」，但详情里某模型是「来源待处理」 | 两个层级口径：列表看"有没有生效绑定"，详情看"每个模型的状态" |
| 北辰云算列表显示「**潜在客户**」，但详情里有个模型「已禁用」 | 同一个道理：`DISABLED` 不计入"已开通"，所以列表判成潜在；详情照样显示那条禁用绑定 |
| 「确认停用」后模型行整行消失 | 投影以未归档绑定为驱动，归档后不再显示 |
| 只有绑定没有报价的客户，合作阶段显示「已有」 | 本轮把「有生效绑定」也算作已有合作（与原型一致） |
| 「已开通模型数」点完确认停用后数字不变 | 只算 `ACTIVE`；「来源待处理」本来就不计入。**看模型行消失，不要看数字** |
| 点「新建报价」选不到候选资源 | 候选资源要求"有效测试证据"，而本轮禁止跑测试。**环境限制，不是缺陷** |
| 「重新上架」计划被拒绝 | 同上，上架要求测试证据 |
| 完成节点时没看到"你是不是指定办理人"的校验 | 客户侧刻意不做（内部运营动作，`M8:E` 已足够）；指派只决定待办落到谁那里 |
| 「手动更新」按钮灰的 | 自动抓取未接入，设计如此 |
| 供应商详情「测试配置」区块空/报错 | 该依赖未装配（存量问题，非本轮） |
| 在客户详情页直接改地址栏 URL 跳到另一个客户，看到的是**上一个客户的数据** | 既有缺陷：详情页没有监听路由参数变化，不会重新加载。**测试时请从客户列表进入详情，不要在详情页之间直接改 URL** |

## 3.5 后端挂了怎么办

测试期间后端掉过一次（进程消失、8080 无监听），已恢复，数据无损。**这不是代码崩溃**，是本地开发进程被回收——我这边起的后台进程会随会话结束被清理。

**如果你要长时间点，建议自己起一个前台窗口**（这样不受我这边影响）：

```
双击仓库根目录的  dev-backend.bat
```

它会自己 build 然后前台运行，窗口不关就一直活着。看到 `http server starting` 就可以点了。

判断后端活着：浏览器里任何列表能正常加载；或访问 `http://127.0.0.1:8080/healthz` 返回 `{"db":"up","status":"ok"}`。
