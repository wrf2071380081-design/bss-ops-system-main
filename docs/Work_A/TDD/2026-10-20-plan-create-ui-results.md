# F13 创建上下架计划页面

日期：2026-10-20。依据原型vPlanCreateForm（641行）与DEC-010。

资源详情增加“创建上架/下架计划”入口，按当前资源实际状态派生方向，仅绑定采购人且有接入历史时显示。表单包含原因、预计时间和不可修改的当前执行人；不收取实际操作确认，后者属于执行登记阶段。

打开后独立检查ONLINE/OFFLINE两种计划的PENDING/EXECUTING分页，任一查询失败禁止保存并可重试；已有同维度计划显示提示并禁止保存，不从当前计划页推断全集。该检查只用于交互，后端仍需同事务验证唯一性、资源revision和B未应用配置变更。

保存POST只传resource_id/expected_resource_revision/kind/due_at/reason，日期按浏览器本地输入转换带时区UTC。幂等生命周期保留503重试键；403/409保留输入并要求刷新核对。响应核对对象、区域、方向、初始版本、依据、原因及预计时间。成功刷新计划面板，资源实际状态保持原样。
