# F4 供应商主体切片计划

依据：[F4 契约 §1](../supply/supply-suppliers.draft.md)、DEC-007、A详细设计 §3.4/5.1/8.2。

- [ ] 先测试税率比例边界、精度及格式、显式区域/币种、可选联系资料；不得浮点或默认为零税率。
- [ ] 先测试采购绑定与版本保护、区域历史使用锁定、无变化留痕、普通编辑保留 established 和 buyer、资料与日志回滚。
- [ ] 记录缺实现红色，新增 `supplier.go` / `supplier_service.go` 及独立端口，不触碰旧业务表和公共迁移。
- [ ] 依据已确认初始绑定策略完成 Create；人员/币种/历史使用事实从事务适配提供，不接受客户端自报有效性。
- [ ] 进行针对授权或区域锁的变异测试；恢复后跑领域/API回归、vet和编译，归档结果。

本轮范围是主体独立业务能力。真实CRUD页面、HTTP与仓储、网站账户和资质仍需后续接入，不以替身替代真库验收。
