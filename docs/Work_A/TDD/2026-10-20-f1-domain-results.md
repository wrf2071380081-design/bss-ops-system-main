## 1. 本次交付范围

新增价格项、结构化官方资料、标准模型聚合、完整性与可报价判定、维护人/revision 校验、核验与不可变副本，以及同事务写当前投影/版本/操作记录的领域服务和适配端口。

这是一项可测试的独立代码交付，不表示完整 F1、新数据库、API 路由或原型页面已完成。运行中的旧 API/前端没有因本次源代码提交自动切换到新模块。

## 2. 原型与讨论结论复核

- 原型 `opValidateModel` 校验八类资料、文本输入输出价及图片/视频/音频相应任务价格。领域沿用此核验与可报价门槛。
- 不完整资料保存为待补齐是用户明确确认的补充交互；不能将它称为原型已有的正式入库行为。
- 原型1009行是批次提交门槛，1012行是进入办理时资源生成；974行整批接入行为按用户确认的逐资源测试门槛修正。
- 模型默认维护人绑定当前创建者；常规维护不承担转交。
- 原型文件浏览器观察受 file: 协议策略限制，本次只做源码复核，没有宣称完成视觉截图比对。

## 5. 需求对应证据及边界

| 用例 | 本切片已验证 | 尚需接入证明 |
|---|---|---|
| A01 | 待补齐可保存、缺失路径、核验失败、不可报价 | HTTP/页面保存与错误展示 |
| A02/A03 | 核验增版、变更撤销核验、旧快照价格保留 | 真实版本表及 operation_log 一致性 |
| A04 | 零价与未知、同任务不同条件、模态对应计费、精度拒绝 | 实际 JSONB/DTO 映射及原型展示 |
| A05 | 两个相同 revision 命令仅一个在串行事务替身中成功 | PostgreSQL 锁/CAS/并发隔离，数据库唯一约束 |
| A08 | 非维护人领域写入/核验拒绝 | 认证主体、公共绑定与 HTTP 403 映射 |
| A10 | 来源链接不接收用户密码段/常见密钥参数，价格来源也交给官方策略 | 真实来源策略、API 安全 DTO、整体日志脱敏 |

事务内存替身只替换当前未交付的持久化边界；来源策略替身只用于受控测试。它们不作为正式集成实现。未配置来源策略时，服务拒绝核验。
