# F3 资源读取与模型广场独立切片

依据：[F3契约](../supply/supply-resources.draft.md)、DEC-002/003及最新A详细设计 §6/8.3。

- [x] 先测缓存计数精确比例与百分比、0命中、缺失/不适用/未测试区别，拒绝错误报告身份和非法计数。
- [x] 先测资源可报价必须同时满足自身测试、目标版本、正式配置版本、模型核验、供应商与区域条件；返回不得含正式密钥或URL。
- [x] 先测广场过滤后聚合、供应商去重、系数范围、可用数、模型分页；flat与grouped计数独立，空值末尾与稳定ID为仓储义务。
- [x] 记录红色并实现资源安全读取领域及端口，不建临时表、不写旧表，不为缺失B事实默认放行。
- [x] 接入A的独立HTTP注册器，验证读取身份、查询白名单和分组/资源响应；运行领域/API回归、vet、编译，归档边界。

目标SQL适配必须在模型分组后分页，并返回所选模型完整成员（不能资源页截断后聚合）。替身只能验证领域聚合和调用协议，不证明真库执行计划、隔离及完整A14。
