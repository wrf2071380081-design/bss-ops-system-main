## 0. 结论摘要

- 中间件 `internal/api/middleware/auth.go` 的 `DataScope()` **确为空实现**（仅 `c.Next()`，142-148 行）→ 行级过滤**完全依赖 repo 层主动拼 WHERE**，无兜底。
- 共核对 `internal/repo/*.go`（29 个非测试文件）返回业务数据的方法，三分类：
  **已过滤 42 / 未过滤但正当 96 / 可疑 19**（静态推断）。
- 对「可疑」项按任务书要求**用真库实测**（两不同数据域账号对比）。实测结论：
  - **确认越权（实测，3 个）** —— 均在「客户报价」详情/写操作上，**SELF 账号可跨域读+写他人报价**
  - **设计性不隔离（实测，1 个）** —— `/quotes/anomalies` 有意不做归属过滤，但对 SELF 角色暴露他域供应商名与报价
  - **静态疑似、实测不成立（多个）** —— 如 `LoadCustomerByID` 等无独立 HTTP 入口，调用方已用 `CheckCustomerScope` 兜底
- **根因单一**：`/customer-quotes/:id/*` 三个接口的 handler 只校验「已登录」，随后直接按 path 参数 `id` 取数/写数，**service 层与 repo 层都没有 `CheckCustomerScope` 调用**，与会话数据域完全脱钩。

## 2. 未过滤但正当（96 个，静态推断，抽样说明）

按类别归纳（不逐条展开，均为「全局主数据 / 系统作业 / 开放接口 / 聚合统计」）：

## 3. 可疑 / 确认越权

### 3.1 确认越权（**实测复现，含硬证据**）

#### 🔴 V1 · `GET /api/internal/customer-quotes/{id}/export` —— 跨域导出他人客户报价（读）

- **位置**：`internal/api/customer_special.go:179`（handler，仅判 `OperatorFrom(c)!=nil`）；`internal/domain/customer/export_service.go:55-82`（`GenerateXLSX` 只 `LoadQuote(id)`，无 scope）；`internal/repo/customer_special.go` 的 `LoadQuote`=`WHERE id=?`。
- **复现**：
  ```
  # smoke_sales = staff:2，数据域 SELF；quote 2 的 owner_sales_operator_id = 7
  curl -H "Authorization: Bearer <smoke_sales>" \
       http://127.0.0.1:8080/api/internal/customer-quotes/2/export?format=xlsx
  ```
- **证据**：HTTP **200**，返回 6300 字节合法 xlsx；解包 `xl/sharedStrings.xml` 得
  `客户报价 #2（v2）`、客户 `?9a`（=customer 1，owner=staff7）、`APPLY`、`EFFECTIVE`、`unit_price`。
  → **SELF 销售成功导出他人客户的报价明细（含售价）**。

#### 🔴 V2 · `POST /api/internal/customer-quotes/{id}/refresh` —— 跨域改写他人报价（写，产生新版本）

- **位置**：`internal/api/router.go:379`（仅挂 `M9:Edit` + 幂等）；`internal/domain/customer/refresh_service.go`（无 scope 校验）。
- **复现**：`smoke_sales` POST `/customer-quotes/4/refresh`（quote 4 owner=staff7，DRAFT）→
- **证据**：HTTP **200**，`data.quote_id=8, new_version_no=5`；DB 中新建 `customer_quote id=8, owner_sales_operator_id=7, version_no=5`。
  → **SELF 销售成功为他人的报价单创建了新版本**（写副作用，已回滚，见文末）。

#### 🔴 V3 · `POST /api/internal/customer-quotes/{id}/special-price` —— 跨域对他人报价发起特价申请（写，产生审批单）

- **位置**：`internal/api/router.go:374`（仅挂 `M9:Edit` + 幂等）；`internal/domain/customer/special_price_service.go:187`（只 `LoadQuote(quoteID)` 校验存在/DRAFT，无 scope）。
- **复现**：`smoke_sales` POST `/customer-quotes/4/special-price`，body `{"reason":"越权探测","expected_margin":"0.20"}` →
- **证据**：HTTP **200**，`data.change_request_id=9, status=PENDING`；DB 中 `change_request id=9, created_by=staff:2, payload.customer_quote_id=4`。
  同时 `audit_log` 记 `id=147 SPECIAL_PRICE_REQUEST / id=148 QUOTE_REFRESHED, operator_id=2, target=4`。
  → **SELF 销售成功对他人报价发起特价审批流**（写副作用，已回滚，见文末）。

> **共性根因（V1/V2/V3）**：三个接口都以 path 里的 `{id}` 为准直接取数/写数，**handler / service / repo 三层都没有把会话数据域（`scopeOf(op)` / `OwnerScope`）传下去**，也没有调用已有的 `CheckCustomerScope`（该函数在 9a 的 `GetQuoteContext` 里就是正确姿势，9b 的三个接口漏了）。与会话 `data_scope` 完全脱钩 —— **任何持有 M9:V / M9:E 的 SELF 角色均可跨域操作**。

### 3.2 设计性不隔离（**实测确认，但与既有裁决冲突，需产品确认**）

#### 🟠 V4 · `GET /api/internal/quotes/anomalies` —— SELF 角色可见他域供应商名与报价

- **位置**：`internal/repo/supplier_lifecycle.go:441 LoadAnomalyRows`，注释明确「**不做归属过滤**（§3.2 放开比价决议，5d 裁决 8）」；`lifecycle.go:548` 调用处同样不加 scope；handler `quotes_lifecycle.go:199` 只挂 `M4:View`。
- **复现/证据**：`buyer_a`（staff4，**SELF**）GET `/api/internal/quotes/anomalies` → HTTP 200，返回 2 行，其中
  `quote_sheet_id=31, supplier_name=供应商乙, sku=claude-opus-4-2026-05`（**供应商乙 属 buyer_b**）。
- **判定**：**实测确认** SELF 角色确实拿到了他域数据。**但**这是文档/裁决写明的「平台级市场比价信息」有意放开 → 属**设计决策与数据域契约的冲突**，不是编码疏漏。需产品裁决：
  (a) 承认「比价属平台级」→ 改数据域契约文档，并把该接口的角色门槛收紧到非 SELF（如仅 PRICING_OP/FINANCE/ADMIN）；
  (b) 维持 SELF 隔离 → 给该接口加 owner 过滤。

## 4. 建议修复方向（供后续批次，不在本批执行）

1. **V1/V2/V3（必修）**：在 `customer_special` 三个 handler 里取 `scopeOf(op)` 传 service，service 内先 `CheckCustomerScope(quote.customer_id, scope)` 或新增 `CheckQuoteScope(quoteID, scope)`（quote 归属 = `owner_sales_operator_id`）；越域返回 403。**参照同一路径 9a 的 `GetQuoteContext` 正确写法。**
2. **V4（需裁决）**：见 3.2，先定「比价是否平台级」再决定改契约还是加过滤。
3. **系统性建议**：`DataScope` 中间件为空是**设计选择**，但缺少「漏拼即越权且无报错」的护栏。建议补一层**测试护栏**：为每个返回业务列表/详情的 repo 方法加一条「SELF 账号跨域必 403/空」的回归用例（可参考本次的实测对，用 `buyer_a` vs `smoke_admin`、`smoke_sales` vs `smoke_sales_b`）。
