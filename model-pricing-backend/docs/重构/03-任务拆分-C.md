## 四、业务规则

1. **报价单客户必填**（`customer_id NOT NULL`）。
2. **区域一致性**：报价单区域必须 = 客户区域 = 资源区域；跨区域报价拒绝。
3. 定价：`s = c/(1−g)`；毛利率 <100%；毛利率/销售系数至少填一个。
4. **毛利 <3%**：允许出单，但必须 `margin-confirm`（记人/时间/理由/当时毛利），否则不能导出；写 `margin_override` + `operation_log`。
5. 报价快照：行上存 `coefficient/margin/sale_coefficient/discount/price_items_snapshot`，历史不重写。
6. 客户开通：同一 `(customer, resource)` 未归档唯一；状态 `已开通/待禁用/禁用待执行/供应下架停止`。
7. 绑定：销售只能改自己名下客户的报价；采购只能改自己名下资源；办理人只能完成自己的节点（403 反例必须测）。
8. 留痕：所有写接口**同事务**写 `operation_log`；提供 helper `oplog.Write(tx, ...)`，业务写与日志同成同败。
9. 税率不参与报价/毛利。
10. 客户无账号、无登录。

## 五、状态机

- 客户开通：`ACTIVE → PENDING_DISABLE → DISABLE_PENDING → SUPPLY_OFFLINE_STOP`；可 `重新配置` 回 ACTIVE。
- 报价：`DRAFT → ISSUED → ARCHIVED`（可加版本）。

## 六、验收标准

- 建客户 → 分配销售 → 建报价 → 选资源 → 填毛利/系数 → 行上毛利正确。
- 毛利 2%：能保存，但导出前必须二次确认；未确认导出 → 409/400。
- 毛利 2% 确认后：`margin_override` + `operation_log` 有记录。
- 跨区域报价 → 400。
- 客户开通：已开通/待禁用/重新配置三种操作走通；重复开通 → 409。
- 非销售本人改报价 → 403；非采购本人改资源 → 403；非办理人完成节点 → 403。
- 工作台：待办 / 操作记录 / 指标正常展示，过滤可用。
- 每个实体的「操作记录」能按 `entityType/entityId` 查出来。
- Excel 导出字段按最终确认的列（待定）。
