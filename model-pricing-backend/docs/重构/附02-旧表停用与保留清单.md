# 05 · 旧表停用与保留清单（2026-10-20）

> 背景：已拍板**新模块一律用 000033 的新表**。
> 本清单用于标识旧表去向，避免有人误用"两套数据源"。
> 执行纪律：**新代码只读写"新表"；"停用"旧表只允许旧代码/历史查询碰，不再新增写入。**

## 三、待评估（先保留，别急着动）

| 旧表 | 问题 |
|---|---|
| `todo_task` | 工作台待办还在用；新办理节点是 `onboarding_node`。是否合并/双写待定 |

---

## 四、执行纪律

1. 新写的 domain/repo **只 import 新表**；代码评审时看到停用旧表要打回。
2. 旧模块（被 feature flag 关掉的那批）仍可能读旧表——这是允许的，因为它们已不对外。
3. 删表要等"旧代码完全下线 + 数据迁移"之后，单独排期；本版**不删**。
4. 需要旧表→新表的数据迁移时，单独写迁移脚本并留存对照关系（id 映射）。
