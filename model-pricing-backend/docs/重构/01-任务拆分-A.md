## 二、数据模型

### 2.1 标准模型（新表 `standard_model`）
000033 已建 `standard_model` + `standard_model_version`，字段：
company、model_type、name（官方名）、official_id、input/output_modalities、capacity、abilities、
price_items、api_access、lifecycle、sources、checked_at、status。
> 旧 `model_sku / model_family / vendor / model_alias` **停用**（见 `附02-旧表停用与保留清单.md`），新代码不读写。

### 2.2 自动拉取（新表）
- `crawl_job.standard_model_id` → `standard_model.id`
- `crawl_diff.standard_model_id` → `standard_model.id`
- `crawl_diff`：field、old_value、new_value、source_url、quote、confidence、status(PENDING/ACCEPTED/REJECTED)。

**规则**：价格/计费单位**绝不静默覆盖**；只生成 diff，人工确认后写回。

### 2.2.1 测试报告补缓存统计（v0.22）
`test_report` 已增两列（000034，已应用）：
- `cache_hit_tokens bigint NULL`（命中输入 Token）
- `cache_input_tokens bigint NULL`（总输入 Token）
展示按公式计算；两列为空或非法时显示"未提供"。**不改写历史快照**（v0.20 共享规则）。

### 2.3 供应来源（新表 `resource`，000033 已有）
- `standard_model_id` → `standard_model.id`；`supplier_id` → `supplier.id`。
- 字段：supplier_model_name、region(CN/OVERSEAS)、coefficient(0,1]、test_base_url、test_api_key_enc、state、ever_admitted、buyer_id、latest_test_report_id。
- 唯一：`(supplier_id, standard_model_id, region)`。

### 2.4 供应商（新表 `supplier` + 两张子表）
- `supplier`：name、region、registration_no、contact、phone、established、tax_rate、settlement_currency、credit_amount、website/account/password_enc、status。
- `supplier_formal_config`（scope/base_url/api_key_enc）、`supplier_qualification`。
> 旧 `supplier_profile / legal_subject` **停用**（见 05 清单）。

### 2.4.1 合同与授信（新表）

- `credit_line`：subject_type/subject_id、direction(SUPPLIER_TO_US/US_TO_CUSTOMER)、amount、currency、version。

### 2.5 计划/公告（新表）
- `plan`：resource_id、kind(ONLINE/OFFLINE/PRICE_CHANGE)、reason、due_at、before/after、status。
- `notice` + `notice_read`。

## 四、业务规则（必须实现）

1. 标准模型资料不全（官方身份/规格/能力/API/生命周期/来源/核验日期）→ `verify_status=待补齐`，**不可报价**。
2. 拉取差异：**价格类字段必须人工确认**；确认/拒绝都要留痕。
3. resource：`coefficient ∈ (0,1]`；同一 `(supplier, model, region)` 唯一。
4. 一个资源只服务一地：国内/海外拆两行。
5. 资源状态机：`待测试 → 待接入 → 已接入 → 已下架`；计划态 `下架计划/上架计划`。
6. 登记接入/下架/上架都写 `operation_log`，记 before/after。
7. 供应商税率**不参与报价/毛利**，只做资料。
8. 列表排序：列头升/降序，**空值排末尾**。

## 五、验收标准

- 真库 E2E：建标准模型（含 8 列字段）→ 拉取生成 diff → 接受 → 字段更新 → 留痕可查。
- 建供应商 → 配正式接口 → 建 resource → 模型广场能看到"供应商数/系数区间/状态"。
- 资源状态流转（待测试→待接入→已接入→已下架）全部走通，非法迁移 409。
- 同 `(supplier, model, region)` 重复建 → 409/400。
- coefficient 越界（0 或 >1）→ 400。
- 排序空值在末尾（前后端一致）。
- 标准模型库有「操作」列（维护）；模型广场有「详情」列。
- 模型详情的「输入缓存命中率」：300/1000 → `30.00%`；缺数据 → `未提供`；详情弹窗显示命中/总数/场景。
- 权限：读取全员可见；改资源/供应商只有归属采购人可操作（403 反例）。
