## 〇、按你的口径纠偏（最终版 · 2026-10-19 晚）

### 0.1 权限：不是"角色"，是"身份/绑定"

- **读取：内部全员可见**（所有人都能看所有数据）。
- **操作：部分动作只有"绑定/特定的人"能做**（如某客户绑定的销售、某模型的采购人、某节点的办理人）。
- 所以原型里的**「林舟·领导/陈乐·员工」用户切换、客户「销售归属」、节点「办理人」都要保留**——快速切换只是为了演示方便。
- 这不是传统的角色权限（没有财务/客户等角色划分），而是**归属/绑定式的操作管控**。权限基础设施保留（业务不删，可注释；未来上角色再开）。
- 绑定的业务意义很重要：**明确谁干了哪些事**（销售归属、谁采购的、谁办理的）。

### 0.2 客户：BSS 不给客户登录

- **取消客户自助门户**。客户在线上沟通，我们生成报价单 → **导出 Excel（字段待定）** → 微信发给客户。
- 现有 BSS 的 `/customer` 门户可以下线/不迁。
- 报价单页需要补"**导出 Excel**"能力（原型只有"导出报价单"，格式待定）。

### 0.3 定价：去掉通道费/折损率 + 3% 软门槛

- **去掉** `通道费、折损率`；成本口径 = 官方价 × 采购系数。
- 毛利 `g = 1 − 采购系数 c / 销售系数 s`；报价按 `s = c/(1−g)`。
- **毛利 >3% 正常；<3% 也允许给客户，但操作者必须二次确认。**
- ⚠️ **原型现状是"毛利 <30% 就预警"**（源码 `i.margin < .3`，文案"低于 30%"），与你的 **3%** 不一致，必须改阈值。
- 二次确认要留痕（记人/记时间/记当时毛利）。

### 0.4 审批：这一版不引入

- 原型仍有「供应商报价-待审批/审批记录」「申报状态-待审批/通过」，**要摘掉**。
- 「客户模型开通」原型已是"选下一节点办理人后直接创建任务"（无审批），按这个模式推广。

## 三、核心业务规则（从界面反推）

- **三层数据主线**：标准模型（catalog）→ 供应来源资源（resource：供应商×模型×平台）→ 客户开通关系（link：客户×资源×模型）。
- **定价**：
  - 采购系数 `c`（对官方价的乘数，供应商侧叫"采购倍率"）
  - 销售系数 `s`；当前毛利 `g = 1 − c / s`
  - 报价按 `c` 与 `g` 求 `s = c / (1 − g)`；毛利率与销售系数双向计算
  - **你的新口径**：去掉通道费、折损率；毛利 >3% 正常，<3% 允许但**操作者二次确认**
- **测试**：按模态分（文本=压力+智力；图片=压力+图片专项；视频=压力+视频专项；音频↔落入视频专项，疑似遗漏需确认）；指标 连通耗时/RPS/TPS；报告人工登记。
- **双平台**：国内/海外（部署节点、签约主体、B 端）。
- **授信方向**：供应商→我方（采购授信）、我方→客户（销售授信）。
- **状态字典**：资源 `待测试/待接入/已接入/已下架`；客户开通 `已开通/待禁用/禁用待执行/供应下架停止`；合同 `办理中/已归档`。
