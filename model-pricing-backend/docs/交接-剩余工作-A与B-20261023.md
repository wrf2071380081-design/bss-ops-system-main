## 4. 约定与坑（希望别重复踩）

- **404 会被前端翻译成「数据不存在或当前账号不可见」**，所以缺接口在界面上看起来像「没数据」。新增前端页面时建议把 404 单独提示成「接口未实现」，别让人误判。
- 供应商 / 客户门户一律**不挂 `RequirePerm`**（这两个角色零内部权限点），隔离靠仓储层 `WHERE supplier_id/customer_id = 登录态`。
- 写接口必须挂 `Idempotency-Key`；幂等中间件在 handler **之前**，所以探测权限要用「唯一幂等键 + 空 body」三档分级：403=没权限点 / 400-404-409=鉴权已过。
- 迁移只新增、不改历史；本地是 PG15、线上是 PG14.24，别用 15 才有的语法。
- 门禁：`gofmt -s -l .` / `go build ./...` / `go vet ./...` / `go test -count=1 -p 1 -vet=off ./...`；前端 `npm run typecheck && npm run build`。
